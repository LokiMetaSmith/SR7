# Shadowrun 7th Edition (Fan Made) Chummer5a Plugin

This directory contains a prototype C# plugin and sample custom data XML files to integrate the "Fan made Shadowrun 7th Edition" rule set into Chummer5a.

## How it works

Chummer5a handles "House Rules" and alternative rule sets through a combination of two mechanisms:

1. **Custom Data Files (XML):** To add new qualities, attributes, metatypes, and gear, you should use Chummer5a's `custom_*.xml` functionality. By dropping XML files (e.g., `custom_sr7e_books.xml`, `custom_sr7e_qualities.xml`) into Chummer5a's `data/custom/` or `data/` directory, the application will automatically merge your new content with the base Shadowrun 5E content.
2. **Plugins (C#):** Advanced behavior that cannot be handled simply by adding data requires writing a C# plugin. The plugin interface (`IPlugin`) allows for dynamic UI changes, menu additions, and catching/modifying calculation events.

## Files provided:

* **`analyze_rules.py`**: A Python script in the repository root that parses `rules.md` and generates statistics about weapon damage and quality karma costs to help balance the custom rule set.
* **`chummer_plugin/Shadowrun7EPlugin.cs`**: A boilerplate implementation of the Chummer5a `IPlugin` interface. This serves as the foundation for the plugin.
* **`chummer_plugin/Shadowrun7EPlugin.csproj`**: The C# project file needed to compile the plugin.
* **`chummer_plugin/custom_sr7e_books.xml`**: An example XML data file that introduces the "Fan Made Shadowrun 7th Edition" (SR7E) as a recognized sourcebook in Chummer5a.
* **`chummer_plugin/custom_sr7e_qualities.xml`**: An example XML data file demonstrating how to import the qualities found in `rules.md` (e.g., "Acrobatic Defender", "Voice of Experience") with their specific Karma costs.

## To continue development:

1. Copy the `custom_*.xml` files to your local Chummer5a `data/custom/` directory.
2. Expand `custom_sr7e_qualities.xml` and create a `custom_sr7e_weapons.xml` file using the lists generated by `analyze_rules.py`.
3. Compile `Shadowrun7EPlugin.cs` into a `.dll` and place it in the Chummer5a `plugins/` folder to start tweaking the UI or overriding core 5E calculations that the `rules.md` changes.
